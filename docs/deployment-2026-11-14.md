# Развёртывание лабораторных на docker-vl

Дата: 2026-11-14. Сервер: `docker-vl`, `10.50.50.15`.
Swagger Gateway: http://10.50.50.15:8000/docs
Compose: `/root/volovich/Labs/docker-compose.yaml`, проект `labs`.

## Текущий API

- Лаба 1: логика отчёта сохранена. Neo4j возвращает список занятий один раз на группу.
- Лаба 2: `required_room_capacity` равно числу всех слушателей лекции выбранного набора. Поле `total_listeners_count` удалено. `total_enrolled_students` курса сохранено.
- Лаба 3: входные параметры только `period_start` и `period_end`. Ответ — массив отчётов по всем группам. UUID групп остаются внутри ответа. Пустой период сохраняет студентов с пустыми списками курсов.
- Gateway передаёт значения по умолчанию, даже если параметры отсутствуют в URL. Для лабы 3 по умолчанию используется период 2026-09-01 — 2026-09-30.

Пример:

```http
GET /api/v1/labs/lab3/hours-report?period_start=2026-09-01&period_end=2026-09-30
Authorization: Bearer <токен>
```

## Что проверено

- Четыре контейнера приложения работают, перезапусков после запуска нет.
- Все пять контейнеров СУБД имеют состояние healthy. Во время обновления их не пересоздавали.
- SHA-256 исходников в контейнерах совпали с проверенными файлами.
- 74 теста прошли локально и внутри контейнера на сервере.
- Проверены реальные HTTP-запросы с клиентской машины через развёрнутый Gateway, без подмены обработчиков и чтений БД.
- Вход, неверные учётные данные, отсутствие и некорректность токена, параметры по умолчанию и их явная передача проверены.
- Лаба 1: пять сценариев сверены с независимым расчётом по строкам БД, включая пустые результаты и фильтрацию посещаемости.
- Лаба 2: все 32 сочетания семестра и года набора сверены с независимым расчётом. 25 сочетаний дали непустые отчёты. Проверены вместимость, число занятий, уникальные слушатели курса и отсутствие удалённого поля.
- Лаба 3: все 32 группы проверены за обычный и пустой периоды, всего 64 проверки группы/периода. Сверены состав, кафедры курсов, занятия и часы каждого студента. В обычном отчёте 160 студентов.
- Шесть проверок некорректных параметров прошли. Двенадцать параллельных запросов вернули ожидаемые ответы.
- Связи Neo4j и свойства, используемые для фильтрации, сверены с PostgreSQL.
- В журналах приложения не найдено `ERROR:` и traceback после проверок.
- Контрольные суммы содержимого девяти таблиц PostgreSQL, узлов и связей Neo4j, иерархии MongoDB и материалов Elasticsearch совпали до и после обновления. Генераторы не запускались.
- Redis штатно пополнился профилями студентов: 160 ключей после проверок.

## Ограничения

Это функциональные проверки на текущей синтетике и небольшой параллельный прогон, не длительное нагрузочное испытание. В тестовом окружении остаются предупреждения Starlette/httpx и о незакрытом Neo4j driver при завершении тестового процесса.

Порты 8001–8003 по-прежнему опубликованы напрямую, сервисы лабораторных собственной JWT-проверки не имеют. Защита Gateway не запрещает обход через эти порты. Сетевую изоляцию и правила firewall в этой задаче не меняли. Старые диаграммы с выбором одной группы и максимумом вместимости одной группы не обновлялись под новый контракт API.
